# Entwurf

`Stockkarte App.dc.html` ist der Entwurf aus Claude Design, aus dem diese App
entstanden ist. Er liegt hier als Nachschlagewerk für Farben, Abstände und
Beschriftungen — die App selbst benutzt ihn nicht.

Farben und Schriften daraus stehen als CSS-Variablen in `public/styles.css`.
